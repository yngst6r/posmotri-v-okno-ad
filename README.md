# Проект «Посмотри в окно»

[![Tests](https://github.com/yngst6r/posmotri-v-okno-ad/actions/workflows/tests.yml/badge.svg)](https://github.com/yngst6r/posmotri-v-okno-ad/actions/workflows/tests.yml)

Учебный проект курса Яндекс Практикума по фронтенд-разработке. Приложение
показывает видеозаписи из разных городов и позволяет отфильтровать их по
времени суток.

## Функциональность

- загрузка видеозаписей из внешнего источника;
- поиск видео по городу и времени суток;
- переключение основного видео по клику на карточку;
- подгрузка дополнительных карточек;
- отображение прелоадера и сообщения об ошибке;
- управление интерактивными элементами с клавиатуры.

## Технологии

- HTML5
- CSS3
- Flexbox
- кастомные элементы форм
- псевдоклассы и псевдоэлементы
- БЭМ-именование классов
